# Security Policy

## Supported versions

Mino is in early development: only the latest commit on `main` receives
security fixes. A supported-version matrix will be published with the first
versioned release.

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Use [private vulnerability reporting](https://github.com/hainuoli/mino/security/advisories/new)
with a minimal reproduction, the impact, the affected version or commit, and
the Go version and operating system. If the form is unavailable, contact the
maintainer through their GitHub profile.

Please do not publish proof-of-concept code before disclosure is coordinated.
Reports are handled on a best-effort basis, with no guaranteed response or
remediation deadline.
